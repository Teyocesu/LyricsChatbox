Settling status also retains the observation revision. Media, session-list, Select/reconnect, suspend, resume, exception and disposal invalidations all advance the same source revision, so the shared boundary covers each source.

The previously corrected session, exact-identity, authoritative-anchor, metadata/timeline ordering, reconnect, paused and scrub settlement matrix remains green.
