# LyricsChatbox v0.5.2

This update improves lyric presentation and several interface behaviors.

### Improved

- Adaptive lyric context now responds more intelligently to the available VRChat message space.
- Lyric recovery options now appear only when they're useful.
- Apple Music connection states are clearer.
- Empty Chatbox previews are represented more accurately.
- Long track durations are displayed correctly.
- Update notes are easier to read inside LyricsChatbox.

### Fixed

- Corrected Lyric Context help being attached to the wrong control.
- Removed duplicated lyric recovery actions.
