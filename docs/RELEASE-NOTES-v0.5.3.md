# LyricsChatbox v0.5.3

This update improves performance and several Windows behaviors.

### Improved

- Reduced unnecessary interface work while LyricsChatbox is running.
- VRChat automatic discovery now avoids repeated searches after a destination is found.
- Restoring LyricsChatbox from the tray now preserves a maximized window.

### Fixed

- Reduced repeated Apple Music status updates when no session is available.
- Corrected playback refresh behavior around Windows sleep and resume.
- Prevented duplicate Apple Music volume updates after finishing an adjustment.
