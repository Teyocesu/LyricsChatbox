# LyricsChatbox v0.7.0

Display is simpler to use: profiles, composition, lyric context, presentation and the live Chatbox preview are grouped together. Custom composition has buttons for inserting supported tokens, and message controls appear when the composition uses `{message}`.

The new Decorations menu offers searchable symbols, text art, kaomoji, dividers, frames, hearts, music and status snippets. You can favorite entries or save your own items. Insert a decoration into Custom composition, a rotating message or a Manual draft, with a preview of whether it fits.

Profiles can now cycle through up to 16 messages in the `{message}` position. Choose a 5, 10, 15, 30, 60 or 120 second interval. Rotation pauses when automatic output is unavailable and resumes without sending missed messages. Existing status messages carry over without enabling rotation.

About brings together version and author information, updates, support actions, the data folder and third-party notices. The sidebar now shows whether Output is On or Off separately from a temporary pause.

Spotify Desktop support has been verified with the Microsoft Store version on Windows. LyricsChatbox remains available as an unsigned per-user installer and a portable Windows x64 ZIP. Windows may show a warning for the unsigned installer.

If you return to v0.6.2, back up `%LocalAppData%\LyricsChatbox` first, or avoid editing and saving profiles in v0.6.2 before returning to v0.7.0. The older version can discard rotating-message settings when it saves a profile.
